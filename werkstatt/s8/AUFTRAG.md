## Vitruvians Architektur (ehrlich, ohne Deploy, ohne fremde Server)
1. **Eine Carl-Adresse, zwei „Apps“.** Carl lebt unter https://claude.ai/artifact/EPS4vNiyuWfpjLw4doypcc. Mac: Safari → Ablage → „Zum Dock hinzufügen“ (oder Claude-Desktop-App). iPhone: Safari → Teilen → „Zum Home-Bildschirm“ (oder Claude-App). In beiden einmal bei claude.ai anmelden.
2. **Ein Carl auf beiden Geräten (Sync).** Der ganze Zustand `C6.S` wird zusätzlich privat in der Artifact-Datenbank gespeichert: `data/users/<user.id()>/carl/...` (für andere unsichtbar, auch für den Besitzer nur über die eigene id). Neuer Stand gewinnt (Zeitstempel), Änderungen kommen live über `onSnapshot`. Ohne db (lokale Tests, abgemeldet) bleibt alles wie bisher in localStorage. Grenze: ein Dokument ≤ 256 KiB → bei Bedarf in Teile aufteilen.
3. **Echtes Mitdenken** über `sample` (schon deklariert) – unverändert.
4. **Verbinden mit Claude Code oder Codex (UFO):** Carl zeigt einen kurzen Code-Satz (Nonce). Otto kopiert **eine Zeile** ins Terminal (Mac/Linux/VPS: `claude --version` bzw. `codex --version` muss laufen, dann wird aus Nonce + Werkzeug ein 6-stelliger Code gerechnet; Windows: PowerShell-Fassung). Er tippt den Code in Carl → Carl prüft ihn selbst (SubtleCrypto, gleicher Rechenweg) → `C6.verbindung.setze('verbunden', {wer, wo})` → UFO wacht auf. Ehrlich: Das beweist, dass auf Ottos Rechner Claude Code/Codex läuft; Carl steuert ihn noch nicht. Für den VPS dieselbe Zeile per SSH auf dem Server.
5. **Aufs Handy holen:** Am Computer zeigt Schritt 6 („Wo Carl wohnt“) einen QR-Code der Carl-Adresse – mit dem iPhone scannen, dann „Zum Home-Bildschirm“.
6. **Anleitung** als eigenes Doc (Vitruvian) + kurz in der App (Schritt 6 und UFO).
