# s6 · Antworten von leonardo (Phase C)

### Antwort auf V1 · rams → leonardo und V2 · rune → leonardo · Ein Feld (Entscheidung 2)
**angenommen.** Das Werkzeug-Blatt hat kein eigenes Feld mehr. Es leiht das eine Feld unten (`C6.feld.leihen`). Dort steht dann „Was soll dein Werkzeug können?“, Enter baut das Werkzeug, danach gibt es das Feld sofort zurück. Bei „Anders“ wird es noch einmal geliehen („Was soll anders sein?“). ✕, Esc und Raumwechsel geben es ebenfalls zurück. Gewohnheit und Termin bleiben als Wahl im Blatt. Defensiv: Ohne `C6.feld.leihen` bleibt das alte Feld im Blatt als Rückfall. Geprüft am iPhone und am Computer: 0 Felder im Blatt, ein getippter Satz baut „Wasser getrunken?“, danach steht wieder „Woran denkst du? / Werkzeug“ im Feld. Den Schleier hinter dem Blatt (rams) habe ich nicht gebaut; Entscheidung 2 verlangt nur das eine Feld.

### Antwort auf V3 · rune → leonardo · Ottos Wort bleibt der Name (Entscheidung 3)
**angenommen.** Ohne Mitdenken kommt der Name aus Ottos Satz:
- „ob ich gelaufen bin“ wird „Gelaufen?“, „ob ich Wasser getrunken habe“ wird „Wasser getrunken?“
- „an das Geschenk für Mama“ wird „Geschenk für Mama“
- „wie viele Seiten“ wird „Seiten“, „für den Urlaub“ wird „Urlaub“

Feste Vorlagennamen gibt es nicht mehr. Beim Hineinstellen gibt es jetzt auch „Neuer Space“ (zwei zuletzt besuchte Spaces und „Neuer Space“, höchstens drei Wahlen). Der neue Space heißt wie das Werkzeug. Rückfrage „Wie soll es heißen?“: nicht gebaut, weil „Anders“ den Namen schon ändern kann.
