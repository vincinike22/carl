# s9 · Vetos von Rune und Rams · Vitruvians Entscheidungen

Rune: „Otto vertraut Carl so sichtbar wie nie“ – zwei Stellen verraten ihn noch (Werkzeug-Einheit, Fund in Damals). Rams: Vertrauen hält den Maßstab, wo es in die Handlung eingebaut ist, und wird Bürokratie, wo es als eigene Schicht obendrauf liegt. **Regel ab jetzt: Vertrauen zeigt nur die Ausnahme.**

1. **Freigabe nur für Endgültiges** (rams V1): Umkehrbares zeigt keine Karte, sondern danach einen Satz mit Rückweg („Hängt an deiner Wand. [Abnehmen]“). Die Karte gibt es nur, wenn etwas verloren geht. Alle Bestätigungen laufen über `C6.freigabe` (keine eigenen „Wirklich?“-Pillen). `C6.freigabe` bekommt dafür `umkehrbar:true` → sofort `true` + Rückweg-Satz über `rueckweg:{text, tun}`. → raffael (Kern), hokusai (Teleskop), jung (einzelnes Vergessen), leonardo (Wegräumen).
2. **Werkzeug ehrlich** (rune V1, rams V2): Jeder Eintrag speichert seine Einheit; „auch Minuten“ ergibt einen zweiten Wert statt eines Ersatzes; das Feld nimmt Kommas an (5,2); Ottos Wunschsatz wird nie zur Feldbeschriftung; Wegräumen: „Weggeräumt. Deine Einträge bleiben. [Zurückholen]“. → leonardo.
3. **Damals nur Eigenes** (rune V2): In Damals erscheint nur, was von Otto kommt; Funde nie als „Geschafft“. → jung (mit rothko, falls der Eintrag aus dem Lesesaal kommt).
4. **Gedächtnis ruhig und wahr** (rune V3, rams V3): Herkunft/Gültigkeit nur, wenn sie nicht „von dir · für dich“ ist; Startwerte heißen „voreingestellt“; Sockenfarbe als Wort; zuerst was Carl weiß, Geräte unten; ehrlicher Satz: „Nur du siehst es. Wenn ich mitdenke, liest Claude das Nötige mit.“; ✕ des Buchs nicht über „Himmel“. → jung (✕: raffael, falls Kern).
5. **Verbinden: goldene Mitte** (rune V4, rams V4). nico will ausdrücklich: Claude Code oder Codex + Terminal + VPS schalten das UFO frei – das bleibt. Aber: Das Blatt beginnt mit einem Satz in Ottos Worten; die Zeile ist zugeklappt („Zeile ansehen“) und wird Stück für Stück in einfachen Worten erklärt; dazu fest: „Kopier nie Zeilen von Fremden ins Terminal.“; Codex und Server unter „Andere Wege“ zugeklappt; Claude Code + das eigene Gerät vorgewählt. → stan-lee.
