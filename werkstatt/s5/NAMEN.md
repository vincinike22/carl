# Ein Ding, ein Name (raffael führt die Liste · s5, ergänzt s6)

Gilt für **sichtbaren Text und Bild** (Sätze, Knöpfe, Platzhalter, aria-label, title). Interne API-Namen (`C6.faden`, `C6.strings`, `perlen`, `knoten`, `S.strings` …) bleiben.
Neues Wort gebraucht? Hier eintragen (Zeile unten anhängen), dann benutzen.

## Erlaubt
| Wort | Bedeutet | Beispiel |
|---|---|---|
| **Space** (der, die Spaces) | ein Ort für einen Gedanken, unten; mit Leine, Zetteln, Kernsatz, einem nächsten Schritt | „In ‚Obstgarten‘ hängen“ · „Neuer Space“ |
| **Planet** | derselbe Space von oben, im Himmel | „Neuer Planet“ (es entsteht ein Space) |
| **Sternbild** | zwei verbundene Planeten mit deinem Satz | „Dein Sternbild heißt …“ |
| **Zettel** | was an der Leine hängt | „Der Satz hängt als Zettel in ‚X‘.“ |
| **Leine** | der sichtbare rote Faden im Space | „an die Leine“ |
| **Kernsatz** | der eine wahre Satz eines Space | |
| **Nächster Schritt** | genau einer, optional „bis wann“ | |
| **Brief** | nur: Carls **ein** Brief am Tag | „Ein Brief von Carl liegt da.“ |
| **Nachricht an die Werkstatt** | was über die Nadel an die Werkstatt geht (Testfassung) | |
| **Werkzeug** (s6) | alles, was an der Werkstattwand hängt oder was du dir mit Carl baust. Zwei Arten, ein Name: Denk-Werkzeuge (Gegenspieler, Brücke, Ordnen …) und eigene Werkzeuge (Haken jeden Tag, Zähler, Liste, Termin …). Eigene stehen im Space am Pfosten neben Carl. | „Neues Werkzeug“ · „Ein Werkzeug nehmen“ · „/“ für Werkzeuge |
| **Teleskop** | Werkzeuge von anderen; „Ins Teleskop hängen“ teilt deins | |
| **Samen** (s5) | der erste Zettel eines Space; Carl nennt ihn einmal so | „Dein Satz ist sein Samen.“ |
| **Pflanze** (s5) | der Zustand eines Space auf einen Blick: Samen → Keim → Knospe → Blüte; keine Zahl | |
| **Dein Wochenende** (s6) | der Lernweg: Samstag 1–3, Sonntag 4–6 | „Am Wochenende zeig ich dir alles.“ |
| **Passt / Anders** | die Antwort auf jeden Vorschlag von Carl (Name, Werkzeug) | |
| **Helfer**, **Fund** | die Helferecke arbeitet; was sie bringt, hängt als Zettel im Space | |
| **Himmel**, **Boden**, **Teleskop** | die Höhen | Knopf „Himmel ↑“ / „Boden ↓“ |
| **Zuhause, Werkstatt, Bibliothek, Garage** | die vier Orte im Dock | |
| **Lesesaal** | hinter der Geheimtür: deine Funde und dein Meister-Regal | |
| **Münzen** | nur im Kieselpark verdient, nur in der Garage ausgegeben | |
| **Place** → sichtbar: **Ort** des Space (z. B. „Kaffeehaus“) | das Bild hinter einem Space; nie mit einem Raumnamen (keine Place „Garage“, „Lesesaal“) | „Wo denkst du am liebsten darüber nach?“ |

## Ersetzt
| Nicht mehr sagen | Stattdessen |
|---|---|
| Faden, String, roter Faden (als Wort) | **Space** (unten) / **Planet** (oben); der rote Faden wird nur gezeigt |
| Perle, „liegt als Perle auf …“ | **Zettel** („hängt als Zettel in ‚X‘“) |
| Knoten, Verbindung (als Ding) | **Sternbild** |
| Projekt, Idee, Gewohnheit (als Art eines Space) | **Space** (eine Art gibt es für den Menschen nicht mehr) |
| Blatt (Werkbank-, Gerüst-Blatt) | **Ergebnis** im Projektor, danach **Zettel** im Space |
| Morgenbrief, Fundbrief, Briefe an Carl, Brief an die Werkstatt, Post | Carls **Brief** (einer am Tag) · **Fund** · **Nachricht an die Werkstatt** |
| Schreibstube | **Helferecke** (in der Werkstatt) |
| Festhalten (als Gerüst) | entfällt: jeder Satz ans Feld wird ohnehin Zettel in einem Space |
| **Gerüst** (s6) | **Werkzeug** (intern bleibt `C6.geruest`) |
| Baustein, Gewohnheit, Termin (als eingebaute Teile) | ein **eigenes Werkzeug**, das du dir baust („Gewohnheit“ und „Termin“ sind nur Vorschläge zum Anfang) |
| Harness, Prompt, Tool, Modell-Konfiguration, Agent | sichtbar nie; nur am Wochenende Station 6 („Dein Gerät und dein Modell“) und im Freundschaftsbuch „Mein Sprachmodell“ |
| Lehre, „Carl bringt’s bei“ (als eigener Ort) | **Dein Wochenende** |
| Höhe/Vogelflug/„Vogel“ | **Himmel** |
| Fahrradteil als Space („Daran binde ich …“) | Teile sind nur Teile |
| Schlüssel am Brett (als Name) | sichtbar bleibt das Brett; gesagt wird **Space** |
