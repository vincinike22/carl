# Ein Ding, ein Name · Ergänzungen s12 (raffael führt die Liste; gilt zusätzlich zu `werkstatt/s5/NAMEN.md`)

Gilt für **sichtbaren Text und Bild** (Sätze, Knöpfe, Platzhalter, aria-label). Interne Namen (`C6.werkzeug.rezeption`, `c6rz-*`, `sid`, `spec`) bleiben.

## Erlaubt (neu)
| Wort | Bedeutet | Beispiel |
|---|---|---|
| **Rezeption** | der erste Raum: Carl am Tresen, ein Satz von dir, ein Werkzeug von ihm. Fünfter Ort im Dock, ganz links. | „Rezeption“ (Raumname, Dock) |
| **Beispiel** | ein kleines, echtes Werkzeug an der Rezeption, aus einem unserer eigenen Sätze; nie gespeichert, trägt keine Namen und keine echt wirkenden Zahlen. Antippen = Carl baut genau dieses für dich. | „Ein Beispiel“ · „So eins für mich“ |
| **Das hab ich mir gemerkt** | Carls Satz nach „Passt“ und die Karte darunter: nur dein Satz und der Name des Werkzeugs, nichts weiter. | Karte „Das hab ich mir gemerkt“ · Zeilen „Dein Satz“, „Name“ |
| **Stimmt so nicht** | der eine Weg, Gemerktes zu berichtigen (wie im Freundschaftsbuch); öffnet „So stimmt es“ mit Satz und Name. | Link „Stimmt so nicht“ → „So stimmt es“ / „Doch so lassen“ |
| **Gedacht** (Kosten-Zeile) | die eine ehrliche Zeile unter der Karte: gemessene Sekunden und wer gedacht hat (dein Rechner · Claude über claude.ai), oder: „das ist eine Vorlage“. Kein Geld, solange keine echte Zahl da ist. | „Claude über claude.ai hat gedacht, 4,2 Sekunden lang.“ |
| **Vorlage** | was Carl ohne Mitdenken aus deinem Satz baut (Bausteine nach Wortsinn). Sichtbar nur in Carls Sätzen, nie als Knopf. | „Das ist eine Vorlage. Probier sie aus, ändern geht gleich.“ |

## Ersetzt / nicht sagen (neu)
| Nicht sagen | Stattdessen |
|---|---|
| Ding (im sichtbaren Text) | **Werkzeug** („Ding“ bleibt Werkstattsprache) |
| Onboarding, Tutorial, Rundgang (an der Rezeption) | nichts davon; die Form spricht. Der Rundgang bleibt nur über `#raum=rundgang` erreichbar |
| Feature, Prompt, KI, Modell, Kopf (als Technikwort) | sichtbar nie; wer gedacht hat, heißt **dein Rechner (Name)** oder **Claude über claude.ai** |
| Spinner, „lädt“ | die gemessene Zahl: „Ich bau … 3 s“ |
| Fehler, ungültig | ein Satz von Carl mit dem nächsten Handgriff („Da kann ich noch nichts draus bauen. Was willst du zählen, abhaken oder nicht vergessen?“) |
